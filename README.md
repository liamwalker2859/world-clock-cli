# World Clock & Meeting Matrix CLI 🌐⏰

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Terminal UI](https://img.shields.io/badge/UI-Terminal-orange.svg)](https://github.com/)

A fast terminal dashboard for distributed remote engineering teams to monitor international developer availability across timezones.

## Features
- 🌍 **Instant Timezone Grid**: Clean tabular view of major developer hubs.
- 🟢 **Work Hours Indicator**: Immediately spotlights who is online vs off-hours.
- ⚡ **Zero External Dependencies**: Pure Python datetime logic.

## Usage
```bash
python world_clock.py
```
